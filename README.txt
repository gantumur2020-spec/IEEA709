I.EEA709 «Цахилгаан системийн найдваржилт, дээшлүүлэх арга зам» — хичээлийн вэб
=================================================================================
Багш: Тэнхимийн эрхлэгч, доктор (Ph.D), дэд профессор Ш.Гантөмөр

Байршуулах (GitHub Pages)
1. GitHub дээр «IEEA709» нэртэй шинэ repository үүсгэнэ (Public).
2. Энэ архивын БҮХ файл, хавтсыг (index.html, Code.gs, README.txt, docs/, pdf/) repository-д хуулна.
3. Settings → Pages → Branch: main, / (root) → Save.
4. Хаяг: https://gantumur2020-spec.github.io/IEEA709/

Сервер (Google Sheets + Apps Script) — аль хэдийн үүсгэж, нийтэлсэн
- Шийт: «I.EEA709 Цахилгаан системийн найдваржилт, дээшлүүлэх арга зам — оноо»
  хуудсууд: EEA709_Оюутан (жагсаалт — багш шууд засна), EEA709_Log, EEA709_БиеДаалт, EEA709_НэгдсэнДүн
- Apps Script төсөл: «EEA709 server»; багшийн нууц үг зөвхөн Script Properties → PW-д хадгалагдана
  (энэ архивын Code.gs-д нууц үг байхгүй).
- index.html доторх API_URL нь энэ серверийн /exec хаяг.

Шинэ жил: EEA709_Оюутан хуудсанд код, овог нэр, ангийг солиход тухайн оюутнууд нэвтэрнэ.
Хувилбар (1–10) = жагсаалт дахь дараалал.

Үнэлгээ: Лекцийн тест 40 + Бие даалт (6 × 5) 30 + Улирлын шалгалт 30 = 100.
